# Snake, Water, Gun Game 🎮

My second game developed using C programming.

## About the Project

This is a simple command-line game where the player competes against the computer by choosing Snake, Water, or Gun.

Both the player and computer make a choice, and the winner is decided according to the game rules.

## Game Rules

- Snake drinks Water.
- Water damages Gun.
- Gun kills Snake.

## Technologies Used
- C Programming
- Standard C Libraries

## How to Run

Compile the program:

```bash
gcc second_game.c -o game
```

Run on Windows:

```bash
game.exe
```

Run on Linux:

```bash
./game
```
